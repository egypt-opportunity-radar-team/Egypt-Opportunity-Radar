# Egypt-Opportunity-Radar
Identifying gaps between Egypt's imports and local production.

## Idea
Egypt imports many products that could be made locally. This project combines trade data (imports and exports) with industrial data to find high-value imported products with little local production, and ranks them as opportunities.
